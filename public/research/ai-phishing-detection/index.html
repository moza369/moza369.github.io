AI-Powered Phishing Detection — Training a Classifier on Email Headers

Building a machine learning classifier to detect phishing emails using header metadata and NLP features.

20 Jul 2025 · 1 min read · MOZA
Ai Machine-Learning Phishing Nlp Research

Abstract

Phishing remains one of the most effective attack vectors. This research explores training a Random Forest classifier on email header metadata combined with NLP features to detect phishing attempts with high accuracy.

Methodology

Dataset

  • Legitimate emails: 5,000 samples from public corpora
  • Phishing emails: 5,000 samples from PhishTank and OpenPhish

Feature Engineering

We extracted 23 features from each email:

import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split

features = [
    'sender_domain_age',
    'spf_result',
    'dkim_valid',
    'reply_to_mismatch',
    'url_count',
    'suspicious_tld',
    'subject_urgency_score',  # NLP feature
    'body_sentiment',          # NLP feature
    'attachment_type',
]

Results

MetricScore
Accuracy96.3%
Precision95.8%
Recall97.1%
F1-Score96.4%

Key Findings

  1. SPF/DKIM failures were the strongest individual predictors
  2. Subject urgency score (NLP) added 3.2% accuracy improvement
  3. Domain age under 30 days correlated with 89% of phishing attempts

Conclusion

Header metadata combined with simple NLP features provides a strong baseline for phishing detection.
